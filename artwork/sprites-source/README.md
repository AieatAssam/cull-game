# Sprite source art

These full-size PNGs are the source artwork for CULL's painted sprite set. The game uses normalized cutouts under `public/assets/sprites/`; the four Urchin LOD frames were built from the reviewed tier strip and normalized with a shared bottom-center anchor. Monitor, Rumour, Swarm, Glass, Bridge, and four Continuity props are included alongside the original cast set.

The art direction, palette identities, world-size constraints, renderer contract, and remaining asset list live in [`docs/ART-DIRECTION.md`](../../docs/ART-DIRECTION.md). `artwork/roster-preview.png` shows the current painted character and prop set; `artwork/sprites-preview.png` shows the initial five-sprite seed set.
